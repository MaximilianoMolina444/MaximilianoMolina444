## QA Tester | Pruebas de API con Postman

Estoy desarrollando mi portfolio de QA y practicando pruebas funcionales de API. Me interesa diseñar casos claros, validar respuestas HTTP y JSON, y documentar resultados y hallazgos con evidencia.

### Proyecto destacado

**Restful Booker API Testing Portfolio**  
Portfolio de pruebas funcionales para la API de demostración Restful Booker.

- Colección de Postman con 112 solicitudes.
- Matriz de 72 casos de prueba y 242 aserciones.
- Evidencias e informe de una ejecución de referencia.
- Los hallazgos están documentados como candidatos; no se presentan como defectos confirmados.
